# 人因與取物引導設計修訂

2026-10-30。這份文件記錄使用者要求修正的十項問題、實際程式邊界，以及尚未完成的真人驗證。產品範圍見 [PRD](PRD.md)，操作驗證見 [FIND_TEST](FIND_TEST.md)。

## 設計原則

使用者決定是否觸摸、如何握持，以及是否接受系統的判定。系統協助定位和接近，不能從影像或距離推論已經實際接觸、可承重或安全。分割遮罩提供可見表面，沒有完整物體幾何、摩擦、重量、溫度或抓取品質。

這次不新增行走導航、醫療建議、外部感測器或應用程式多語言。使用者要求以繁體中文溝通；應用程式現有英文語音保持單一語系。

## 十項問題與對應修正

| 問題 | 實作 | 程式與限制 |
|---|---|---|
| 找到不等於伸手可及 | 每次佩戴先量測舒適伸手距離；目標和中途路點都通過距離檢查；超界停止 | ReachCalibration / ReachProfile。以胸前相機到指尖的穩定距離減三公分作保守界線，並非人體關節模型或臨床評估 |
| 固定軸順序不自然 | 平面物件先抬高、橫移到靠近使用者的可見邊緣，再下降到探索高度；立體物件先在原側對齊深度，再接近可見近側 | ReachApproach。路徑有阻擋就停止，不猜測繞行路徑 |
| 障礙提醒後繼續移動 | 在實際即將指示的軸段檢查指尖、掌心、手腕與前臂近似體積；發現障礙就鎖定停止 | GuidanceSession / 當前 LiDAR 點雲。這只是保守碰撞篩選，不能證明無障礙 |
| 接近被說成接觸 | 近距離或指尖幾何接觸都只開始觸覺探索；說明接觸尚未確認 | StepGuide 的 grab / Phase.grabbing 為舊的程式名稱，現在代表探索／待確認；不代表實際握持 |
| 中心不等於抓取點 | 平面物件選可見近側邊緣；依物件提供邊緣、近側、杯柄探索提示 | 未辨識杯柄或液體，不聲稱已找到杯柄；使用者自行選擇握法 |
| 遮擋被當成使用者錯誤 | 手消失超過 0.5 秒時插播停手並靜音，說明可能遮擋或出框；提供 Check 或恢復到先前位置 | 不要求使用者盲目伸向未知位置；短暫掉點可恢復，定位／相機改變則需新搜尋 |
| 單張影像誤判成功 | 最多三次影像觀測，保留有效證據；其中兩次身份肯定、離開原位且至少兩個相同實際指尖與物件共同移動，才允許自動確認 | HoldVerification / HoldMotion。兩次身份判斷都需肯定，拇指不必可見；手與物件各移動至少三公分，相對位置漂移不超過 2.5 公分，時間間隔 0.35–30 秒；仍可能誤認同類物件 |
| 相機與身體方向混用 | 同一段取物固定方向基準；每個軸使用同一個實際指尖，優先食指；語句明說移動手 | 相機旋轉超過 15° 或位移超過六公分就停止，需重新搜尋；不在伸手途中要求轉身 |
| 定位失效仍引導 | tracking 非 normal、相機更新中斷超過 0.75 秒或 App 離開前景，停止動作提示；舊雲端結果失效 | FindModel 的停止／暫停與 session/check ID。回復正常不自動接續舊路徑；背景後重新量測 |
| 隱藏狀態改變按鍵意義 | 主要區域閒置時開始，任務期間一律停止；另有固定 Stop、Status、Check、自行確認與掃描完成控制 | VoiceOver 標籤、動作與 UI 測試識別碼已加入；實機與 VoiceOver 操作仍待驗證 |

## 狀態與不確定性

1. **設定：** 固定胸前手機，選擇慣用手，量測舒適指尖位置。測量需要至少 0.8 秒穩定資料；無可見食指或手機不穩定時不產生距離。手別是使用者的操作選擇，尚未以 Vision 左右手分類強制驗證。
2. **尋找：** 語意模型挑選候選，LiDAR 估計表面。房間記憶只提供「上次看見」或「可能」的搜尋提示。
3. **接近：** 保持身體不動，依路點移動同一實際指尖。缺少可用表面時不開始動作引導。
4. **探索：** 停止精確位置指令，讓使用者觸覺定位與自然握持；距離不等於接觸證據。
5. **確認：** 雲端比對是事件觸發；最多三次觀測中，兩次身份與共同移動證據足夠才確認。一次漏檢可補取一次觀測，先前有效證據保留；身份否定、逾時或三次仍不足就交給使用者決定，不自動重試。
6. **自行確認：** 使用者可明確記錄自己已拿到，日誌為 user_confirmed，與 hold_yes 的自動判定區分。
7. **停止：** 取消麥克風和後續動作、使待返回結果失效。重新開始必須新搜尋；若手機重新佩戴或 App 曾離開前景，需要重新量測。

## 感測與操作限制

- 當前點雲只能觀察相機視野中的可測量表面；透明、反光、薄小、被遮擋物體可能漏掉。排除手和目標的點也會形成盲區。
- 前臂以手腕向相機方向延伸二十公分近似，配合八公分的路徑間距；不是完整骨架或人體掃掠體積模型。
- 路徑不明時停止。沒有經驗證的自動繞行或「安全抓取點」。
- 舒適距離是使用者量測值，非通用可及範圍。選擇手別並不代表已驗證實際追蹤的是該隻手；一次只展示一隻手。
- 共同移動是更強的證據，仍不是握力、承重、物件身份或實際接觸的證明；同類物件、遮擋和深度誤差仍需實測。
- 長時間辨識不得要求一直懸臂；使用者可先將手和物件保持在有支撐的舒適位置，選擇停止或自行確認。
- 這次不新增真人使用成果。既有蒙眼測試與模擬器結果保留為歷史紀錄，不能推論視障者日常使用成效。

## 參考依據與後續參與

- [CMU PalmSight](https://publications.ri.cmu.edu/palmsight-an-assistive-technology-helping-the-blind-to-locate-and-grasp-objects)：已有定位與非視覺回饋協助抓取的研究；本專案不聲稱首創。
- [Apple 偵測模式說明](https://support.apple.com/guide/iphone/detect-text-read-loud-iph29dbe3fb6/27/ios/27)：其操作限制提醒不能將相機偵測當作導航或高風險用途的可靠依據；此處是設計參考，並非對 Sightline 的驗證。
- 下一輪邀請視障者與定向行動／職能相關專業人士共同檢查語句、佩戴和日常任務。比較使用者原本的方法與 Sightline，記錄時間、碰撞、拿錯誤報、疲勞和外援次數。

補充驗收：持續移動中的軸與可能新指令的軸都需檢查，實際逐軸終點也需在舒適範圍；至少四分之一抽樣深度且不少於十六點有效，才能把障礙點集合視為可用觀測。自身前臂排除與掃掠檢查使用同一近似模型，遮擋區域仍屬未知。確認提示播完後，以本機偵測到的移動觸發下一影格，沒有移動則四秒後只取一次；候選保留自身來源影格的參考裁圖。

身份邊界：每個候選保存自身影格與參考裁圖；沒有參考裁圖時不進行自動成功判定。低信心且被否定或無法驗證的候選不在搜尋放棄時重新拿來引導。Stop 後舊任務即使返回，也不能重新錄音、寫回候選或消耗新確認的配額。

遮擋修訂：同一指尖在短暫掉點時維持選擇，連續缺失超過 0.5 秒才考慮換到其他實際指尖，避免每影格換點令靜止判定不斷重設。立體物件先在原側對齊深度，再進行側向接近；每段仍需通過舒適範圍與障礙檢查，不能保證始終在視野內。

視野邊緣：目標相對相機水平方向超過二十度時，先要求手保持放下、明說轉動身體面向物件，然後重新搜尋；不直接側向伸手，也不在同一取物段偷偷改變座標基準。持有確認仍需兩次可見的至少兩個相同實際指尖；握姿或物件遮住所有可用關節時，只能保留不確定或由使用者自行確認。

## 有限次確認修訂（本輪）

- 身份與持有證據分離：Spark 只比較畫框候選與原參考物件；本機判斷指尖接近與共同移動。兩個指尖接近表面四公分內只是候選，不是握力證明，沒有放寬四公分門檻。
- 每次搜尋最多啟動一次確認循環。循環最多三次 SAM 與三次身份比對、總時限三十五秒；SAM 未找到時略過該張身份比對。明確身份否定立即停止自動確認。
- 觀測時間窗三十秒；最近一百五十毫秒內的同一實際關節可補短暫掉點，不借用未來或更舊的位置。確認仍需至少兩個共同物理指尖：手與物件各位移至少三公分，相對漂移不超過 2.5 公分。
- 原來有支撐面的物件，除了離開原位五公分，還需相對原物件位置上升至少三公分；沿桌面推動不能算拿到。部分表面與深度誤差仍需實機測量。
- 手仍自然移動時先補取觀測；穩定後才考慮要求一次四公分的水平移動。依目前可見空間、伸手界線和障礙選方向，不要求繼續抬高；空間未知就停止自動確認。
- 本機看見至少兩指尖依指定方向移動三公分後擷取；等待最多四秒。超過七公分、伸手越界或手持續消失則插播停手並結束。這不是完整人體或動態碰撞保證。
- 無法確認後，Check 停用；提供自行確認、New search、Stop。GuidanceSession 在等待決定時不再發方向、提示重試或自動要求檢查。使用者自行確認仍記錄 user_confirmed。
- 模擬器使用同一 HoldVerification、HandTrace、HoldMovementPlan 和位移觸發邏輯；虛擬使用者只做一次四公分水平動作，沒有累積向上抬到四十公分的行為。合成失敗保留為 unclear，不偽裝成成功。

本輪審查補強：移動監控從提示播放前開始，持續到雲端確認完成或取消，不在送出影像時提前解除。每影格的新深度／障礙、至少兩個共同指尖、指定方向、七公分上限、伸手界線與視野都可否決動作；反向超過 1.5 公分也停止。持物可見表面的極值與稀疏內點納入掃掠，前一張 anchor 保存自身表面，不混用漏檢／另一候選的表面。這仍不是完整物件背面或人體碰撞模型。手穩定須整個觀察窗口維持，而非只看首尾。

## 2026-10-31 設定頁退出與非視覺操作修訂

使用者實機截圖顯示量測成功後仍停在強制設定 sheet。舊版只加入 VoiceOver 標籤，仍要求找到完成／讀說明按鈕，未滿足非視覺流程。現移除強制 sheet，設定改為頁內覆蓋；成功自動關閉，長按與 VoiceOver 退出手勢隨時可退出，未量測不放行引導。設定大區域與 VoiceOver magic tap 啟動／停止量測，手別切換語音回報，主畫面控制在設定期間隱藏於無障礙樹。程式型別檢查通過不代表實機音訊、手勢、VoiceOver 或盲人使用驗證通過；這些仍待測。主流程仍保留 Check／自行確認等 VoiceOver 控制，尚非全程免觸控產品。
